WATER AI — Windows build

1. Upload all files in this folder to a GitHub repository.
2. Open the repository -> Actions -> Build Water AI for Windows.
3. Click Run workflow.
4. When finished, open the workflow run and download the artifact named Water-AI-Windows.
5. Inside it you will find the Windows installer (.exe) and portable .exe.

IMPORTANT: the HTML app itself may contain API configuration. Packaging as EXE does not hide a client-side API key from users.
